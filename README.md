# Portfolio

My personal portfolio website, built with **React** and **Vite**.

🌐 **Live:** [pelmenchik52.github.io/MyPortfolio](https://pelmenchik52.github.io/MyPortfolio/)

## Features

- Interactive grid background that reacts to the cursor
- Animated hero section
- Expandable project cards
- Responsive layout and reduced-motion support
- Automatic deployment to GitHub Pages

## Tech stack

React 18 · Vite · CSS · GitHub Actions · GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Edit the content

All text, projects and links live in one file: `src/data.js`.

## Deployment

Every push to `main` triggers the workflow in `.github/workflows/deploy.yml`, which builds the site and publishes it to GitHub Pages.
